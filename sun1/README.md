# 3D 太阳系模拟器

一个**纯前端、零依赖、零构建**的 3D 太阳系实时模拟器。基于 [three.js](https://threejs.org/) 构建，所有天体表面、光环与光晕贴图均由 Canvas 2D 在运行时**程序化生成**——无图片、无模型文件、无需网络，浏览器打开即用。

## ✨ 功能特性

- **太阳**：米粒组织、太阳黑子、日珥、日冕脉动、随机耀斑、日冕光流
- **八大行星 + 月球**：实时公转 / 自转，程序化纹理（木星大红斑、土星卡西尼缝光环、地球大陆云系台风、火星火山冰盖……）
- **三大远日带**：小行星带（300）、柯伊伯带（400）、离散盘（200）
- **哈雷彗星**：高离心率逆行椭圆轨道，牛顿迭代解开普勒方程，离子尾 + 尘埃尾随日距变化
- **划过陨石**：对象池化，确定性顶点扰动造型
- **交互**：点击天体聚焦跟随、悬停信息浮窗、图例双向联动高亮
- **科普联动**：点击左侧知识框，对应区域小天体集体脉冲闪烁
- **控制栏**：暂停 / 重置、正视 / 俯视 / 侧视、时间倍速（0–100 天/秒）、太阳系整体旋转倍速（0–20x）
- **视觉效果**：点光源 + PCF 软阴影（土星球体与光环互相投影）、背面加色壳模拟大气 / 日冕

## 🚀 快速开始

无需 Node.js / npm / 任何构建工具，现代桌面浏览器（支持 WebGL，推荐 Chrome / Edge 最新版）即可运行。

**方式 A：直接打开**

```
用浏览器打开 index.html
```

**方式 B：VS Code**

已配置 `.vscode/launch.json`，按 `F5` 启动浏览器。

**方式 C：静态服务器**

```bash
npx http-server . -p 8080
# 访问 http://localhost:8080
```

启动后控制台输出：

```
[Solar System] three.js 128 已启动，天体数量：11，默认速度：40 天/秒
```

## 📐 核心算法

- **开普勒第三定律**：`period = (r / r_earth)^1.5`，保证内圈快、外圈慢
- **开普勒方程**（哈雷彗星）：牛顿迭代解 `E − e·sinE = M`，近日点快、远日点慢
- **球面均匀采样**：`φ = acos(2·rand − 1)`，避免两极堆积
- **水平无缝纹理**：正弦整数波数 + 环绕复制（wrap3）
- **确定性顶点扰动**：坐标哈希伪随机，保证重复顶点偏移一致、表面不破裂
- **固定步长主循环**：16.7ms 步长 + 100ms 帧封顶，后台切回不产生巨步长

## 🏗️ 架构约定

- 每个构建模块返回 `{ …, update(dtMs) }` 句柄，由主循环 `step()` 统一驱动，模块间不互相调用
- `bodies[]` 注册表是拾取 / 聚焦 / 图例 / 浮窗的**唯一事实源**
- `data.js`（SOLAR_DATA）为数据源，驱动所有天体生成
- 脚本按序加载（顺序敏感）：`three.min.js` → `OrbitControls.js` → `data.js` → `app.js`

## 📝 修改与扩展

- **新增行星**：`data.js` 追加对象 → `app.js` 加纹理函数 → `index.html` 加图例条目
- **调速度**：改 `#speed` 滑杆或 `SPIN_VIS` 常量
- **调三大带 / 彗星**：改 `*_COUNT` 与范围常量
- **代码风格**：ES5、模块返回句柄、魔法数字提取为 `UPPER_SNAKE_CASE` 常量、中文注释

详见 [`技术文档.txt`](技术文档.txt) 第 15 节。

## ⚠️ 已知限制

1. three.js r128 非最新版，升级需核对 OrbitControls 与 API 兼容性
2. 纹理随机生成、无固定种子——每次刷新行星外观都不同
3. 单文件 `app.js` 非模块化，函数同处一个 IIFE 闭包，难以单元测试
4. 物理为视觉近似：行星用圆形轨道（仅哈雷彗星解开普勒方程），无 N 体 / 潮汐
5. 移动端（≤640px）隐藏侧边面板，触控拾取可用
6. UI 与文案均为中文，无国际化
7. 速度 / 视角设置无持久化，刷新后丢失
